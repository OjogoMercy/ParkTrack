# Open questions, gaps and conflicts

Found while reading PRD v1.1 against the UI v2 designs. Each has a **default we build to** so nobody is blocked. Change a default only by editing this file in a `contract/*` PR (WORKFLOW §7).

| # | Topic | What we found | Default until decided | Affects |
|---|---|---|---|---|
| Q1 | Repo `PRD.md` | The `PRD.md` at the repo root is the PRD for "Leash" (a USDC vault on Arc), not ParkTrack | Delete or replace it before Scope 01 | all |
| Q2 | OTP length | S02 copy says "We send a 6-digit code" but shows 4 boxes | **Decided:** 6 digits (the S02 screen gets 6 boxes) | 02 |
| Q3 | Fare split | PRD says "fare shares" with no ratio; P03 shows a ₦3,000 fare split driver ₦1,800 / park ₦1,200 | **Decided:** follow the split in the designs: driver 60% / park 40% of the fare, platform keeps the ₦150 service fee; stored per park so it can change later | 04 |
| Q4 | Roadside code lifetime | PRD: codes valid 10 min (COL-2). R02 shows the roadside code right after paying POD, ~1 h before the bus arrives | Counter codes: 10 min. Roadside codes: valid until the trip ends or the parcel is marked Missed; still 5-attempt lock | 03, 07 |
| Q5 | Roadside parcel with no POD | When does a recipient with nothing to pay get their roadside code? | Issued at `load_accepted`, sent with the arrival estimate | 03, 07 |

| Q10 | Departure time | A01/A07 show "Departs 10:30 AM", "admin alerted at 10:15"; PRD `trips` has no scheduled departure | Add `trips.scheduled_departure_at`, set by the agent at assignment | 01, 06, 09 |

| Q17 | Prisma vs Supabase client | PRD says Prisma; Realtime needs Supabase client | Prisma for all reads/writes; Supabase JS only for Realtime subscriptions and Storage | 01 |
| Q18 | Design files location | Designs lived outside the repo | **Resolved:** copied into `docs/design/` (≈9 MB) with the PRD PDF in `docs/`. Treat them as read-only; a new design version replaces the file in a `contract/*` PR | all |
| Q19 | Merge cadence | Fixed target dates per scope | **Decided:** no fixed dates. Each scope merges when it is complete, in order. P0 slices still come before P1 slices | all |
| Q20 | Git remote | The local repo pointed at `zayn-tech-info/leash` | **Resolved:** `origin` is now `github.com/OjogoMercy/ParkTrack`; the old URL is kept as remote `leash` | all |
| Q21 | Per-person push limits | GitHub only lets you say *which people* may push to a branch on repos owned by an **organization**. On a personal repo every collaborator with write access can push wherever branch rules allow | Use rulesets that block direct pushes everywhere (PRs only) and only let the owner merge to `main`. For hard per-person limits on scope branches, move the repo into a free GitHub organization with one team per scope (see WORKFLOW §3) | all |
| Q22 | Package manager | Scope 01 first used pnpm; on Windows it needed a corepack workaround (no admin rights) | **Decided:** npm. It ships with Node; commit `package-lock.json`; no pnpm or yarn lockfiles | all |
| Q23 | Parcel code samples | Several design samples (PT-9X1A, PT-1P9F, PT-6T1R, PT-1C6M, PT-0K7S) contain 0 or 1 | **Decided:** codes never use 0/O/1/I, because agents write them by hand on parcels. Generator and validator enforce it; fixtures use 7/4/8 variants | 01, 06, 08 |
| Q24 | Prisma version | npm's `latest` tag for the Prisma CLI points at an 8.0 release candidate | **Decided:** pin `prisma`, `@prisma/client`, `@prisma/adapter-pg` to 7.10.1 exactly; upgrade together in a contract PR | 01 |
| Q25 | Supabase REST exposure | Supabase serves every `public` table through its REST API to the anon key, which browsers receive for Realtime | **Decided:** RLS on every table with no policies (Prisma bypasses RLS). Scope 07 adds narrow read policies only if it uses Postgres-changes Realtime; Realtime broadcast needs none | 01, 07 |
| Q26 | Install scripts | npm 11 blocks dependency install scripts until approved | Approved and recorded in `package.json` `allowScripts`: prisma, @prisma/engines, esbuild. New packages with scripts need the same one-time approval | all |
| Q27 | Sign-in across subdomains locally | Browsers refuse a cookie with `Domain=localhost`, so with `ROOT_DOMAIN=localhost:3000` a sign-in can't be shared between `ogbomoso.localhost` and `ibadan.localhost` | **Decided:** with a bare `localhost` root the session cookie is host-only (sign-in works per subdomain). To test one sign-in across parks, set `ROOT_DOMAIN` and `NEXT_PUBLIC_ROOT_DOMAIN` to `parktrack.localhost:3000` and open `ogbomoso.parktrack.localhost:3000`. Production (`parktrack.ng`) is unaffected | **Superseded by Q45** (one domain). Was: 02, all |
| Q28 | Recipient link format | Scope 02 planned a jose-signed link; a JWT is ~170 characters, more than a whole 160-character SMS | **Decided:** `<trackingLinkId>.<expiry>.<HMAC-SHA256, 128 bits>` signed with `LINK_SIGNING_SECRET`, ~50 characters. Holds only the parcel's random link id. Default lifetime 14 days; `revokeRecipientLinks` replaces the id so old links stop working | 02, 07, 08 |
| Q29 | Agent home | One AGENT role covers both the origin counter and arrivals | **Decided:** agents land on `/counter` after sign-in and reach `/arrivals` from there | 02, 06, 08 |
| Q30 | Console sign-in | Should an unknown phone on `app.parktrack.ng` get a code (and an account)? | **Decided:** no. The console sends codes only to staff (agent, driver, park or platform admin, not deactivated) and never creates accounts (`not_staff`). Senders sign in on their park's page | **Superseded by Q45** (one domain). Was: 02, 09 |
| Q31 | Rate-limit storage | The schema has no table for rate limits, and adding one needs a contract PR | **Decided:** per-phone code limits count `otp_codes` rows (durable, all instances). Per-IP and scan limits use an in-memory sliding window per server instance behind `RateLimitStore`; add a `rate_limit_hits` table later through a contract PR if a hard cross-instance limit is needed. Callers don't change | 02, 06, 08 |
| Q32 | Supabase connection strings | Which Supabase strings Prisma 7 with `@prisma/adapter-pg` needs | **Decided:** `DATABASE_URL` = transaction pooler (port 6543) for the app; `DIRECT_URL` = session pooler (port 5432) for migrations. Both verified on the real project without extra URL options. `DATABASE_POOL_MAX` is only for the local `prisma dev` database. Supabase Auth is not used (own phone codes + jose session) | 02, all |
| Q33 | What drivers can see | Drivers belong to a park; should they see that park's parcels? | **Decided:** drivers see only parcels loaded on their own trips (`parkScope`). Agents and park admins see parcels leaving from or arriving at their park | 02, 06, 07 |
| Q34 | Park initials tile | S01/S08 show "OG" for Ogbomoso Motor Park, not the initials of its name | **Decided:** the tile shows the first two letters of the park's subdomain ("ogbomoso" → OG, "ibadan" → IB) | **Changed by Q45:** the tile still uses the first two letters of the park's slug, now from its page address (`/parks/ogbomoso` → OG). Was: 02 |
| Q35 | Parcel photo privacy | The plan said uploads return a "public-ish" URL; drop-off, damage, release and collector photos show people and their goods | **Decided:** private Storage buckets only. `publicUrl` is a ParkTrack address (`/api/uploads/view/…`) that checks the viewer (tenancy rules, or the recipient's tracking link) and redirects to a Storage link valid 1 minute; anyone else gets 404. Feature scopes save that address on the parcel event | 03, 06, 07, 08 |
| Q36 | WhatsApp templates | Business-initiated WhatsApp messages must be approved templates; Meta rejects templates that start or end with a variable and only allows one-time codes in AUTHENTICATION templates (no links, no extra text) | **Decided:** two templates. `parktrack_update` (Utility): "Update from ParkTrack: {{1}} Thanks for using ParkTrack." carrying the SMS text. `parktrack_code` (Authentication, copy-code button, no expiry line) for sign-in and collection codes, so on WhatsApp a collection code arrives without the parcel code. Any WhatsApp failure falls back to SMS | 03 |
| Q37 | Termii setup | Termii's base URL is per account (dashboard); the "generic" route doesn't reach Do-Not-Disturb numbers and mustn't carry codes; "₦" and curly punctuation switch an SMS to Unicode (70 characters a page instead of 160) | **Decided:** `TERMII_BASE_URL` setting; `TERMII_CHANNEL=dnd` by default (Termii must activate it); SMS text made GSM-safe ("₦"→"N", curly quotes/dashes to ASCII, accents removed: "Adébáyọ̀"→"Adebayo") | 03 |
| Q38 | Collection code attempts | Should a new code reset the 5-try limit (COL-4)? | **Decided:** no. Wrong tries count per parcel and purpose across reissues; the 5th locks the parcel and a locked parcel gets no new code until an admin releases it (08, V05). New codes at most every 30 s per parcel | 03, 08 |
| Q39 | Message log contents | Messages can hold codes | **Decided:** `notifications` stores who, channel, template, status and error, never the text. Console mode prints messages in development; in production 6-digit codes are blanked from printed text | 03 |
| Q40 | Storage dues details | How fees accrue after the free window, and when they stop | **Decided:** every started day after the window (window from the arrival message, `storageWindowHours`), at the destination park's rate for the size; stops at `maxHoldDays` after the notice and at collection; days already paid (`storagePaidUntil`) aren't charged again. Computed on read, no nightly job | 03, 04, 08 |
| Q41 | Prohibited items | Prohibited goods aren't in the category list, but "Other" + a free description could still name them (BOOK-8) | **Decided:** whole-word screen of the description for the PRD §6.5 list (firearms, fuel/gas cylinders, drugs, live animals, cash/cheques), written to avoid false alarms ("check fabric", "cashew", "fuel pump") | 03, 05, 06 |
| Q42 | Code message expiry text | Sign-in codes last 5 min, counter codes 10, handshake codes not decided yet (06) | **Decided:** code messages don't state a fixed expiry ("use it within a few minutes"); screens show the real countdown. Scope 06 decides handshake code lifetime | 03, 06 |
| Q43 | Pidgin messages (NOT-2) | Language per person | **Decided:** every message has a Pidgin version chosen from the profile (`users.language`); recipients without an account get English. WhatsApp keeps the English template wrapper with Pidgin inside. A native speaker should review the wording before launch | 03, 05 |
| Q44 | Testing parcel flows on Supabase | `parcel_events` is append-only (trigger), so test parcels with history can never be deleted from the real project | **Decided:** parcel-engine flows are tested on the local Prisma Postgres (`npx prisma dev`), with the same schema and seed; Supabase is only used for checks that leave nothing behind | all |
| Q45 | One domain, one account type | Each park had its own subdomain (`ogbomoso.parktrack.ng`), people signed up on a park's address, sign-up made a `SENDER`, and staff used `app.parktrack.ng` with their own sign-in | **Decided (26 Nov 2026):** everything runs on the main domain. One sign-in for everyone at `/signin`; a new phone becomes a **`USER`** (role `SENDER` renamed). Sending or receiving is what a person does with a parcel, not a role: "sender" is `parcels.sender_id` (the `SENDER` actor in the state table is that relationship), recipients still act through signed links. Parks have pages at `/parks/{slug}`; the home page lists parks to pick from. The staff console is `/console/*` on the same domain; staff roles (AGENT, DRIVER, PARK_ADMIN, PLATFORM_ADMIN) are unchanged for now. Old `{park}.` and `app.` addresses redirect (308) to the main domain. The session cookie is host-only. **Next (not decided yet):** park owners register their own park and routes, and whether staff roles become a role at a park | all |
